# 中間報告デモ手順(会社PC)

会社PCで、AI処理をIDEのAIチャット(GitHub Copilot)に手動で中継してデモを実行し、
中間報告スライドに貼る画面とExcelレポートを用意するための手順です。

- 使うデータはダミーの障害票(`data/samples/bug_tickets_demo.csv`、架空データ80件)だけです。実データは使いません。
- 環境構築は済んでいる前提です(`SETUP_FOR_AI.md` のスモークテストまで完了)。

## 1. 最新化

```powershell
git pull
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

DBの構造を変えたので、以前に起動したことがある場合は `data/db/quality.sqlite3` を削除してから起動します。

## 2. 起動

```powershell
$env:PYTHONIOENCODING = 'utf-8'
.\.venv\Scripts\python.exe -m streamlit run app.py --server.headless=true --server.address=localhost --server.port=8501 --browser.gatherUsageStats=false
```

ブラウザで http://localhost:8501 を開き、サイドバーの「AIの呼び先」が **手動中継(IDEのAIチャット)** になっていることを確認します。

## 3. 手動中継のやり方(3工程とも共通)

1. 画面に出たプロンプトを、右上のコピーボタンでコピーする
2. VS Code の Copilot Chat を **Ask(質問)モード** で開き、貼り付けて送信する
   (Agent モードだとファイルを編集しようとすることがあるため)
3. 返ってきた応答を全部コピーし、画面の「AIの応答」欄に貼って「応答を取込」を押す

うまくいかないとき:
- 「応答を読み取れませんでした」と出たら、Copilot に「JSONだけで返してください」と頼んで、もう一度貼り直す
- 結果がおかしいときは「応答を取込み直す」で、やり直せる

## 4. デモの流れ

| 画面 | 操作 |
|---|---|
| 1. 取込 | `bug_tickets_demo.csv` をアップロード → ヘッダ検出を中継 →「3行目をヘッダとして検出」を確認 →「この内容で取込を確定」 |
| 2. 列選択 | 列提案を中継 → 推奨の列と役割を確認(必要なら直す)→「確定」 |
| 3. 行チェック | 対象列「現象」、類似度75のまま「重複チェック実行」 |
| 4. ワードマイニングと重み付け | ワードマイニングを中継 →「この結果を保存して重み付けへ進む」→ 重視したい語の重みを上げて「重みを保存」 |
| 5. 分析結果 | 要注意度の分類は「機能」→ 各タブを確認 →「分析結果をDBに記録」→「Excelレポートをダウンロード」 |

## 5. スライドに貼る画面キャプチャ

| スライド | 撮る画面 |
|---|---|
| 5. 入力 | 取込画面(ヘッダ検出の結果とプレビュー) |
| 6. AIの中間出力 | 手動中継の画面(プロンプトと応答欄)、列提案の結果、ワードマイニングの結果 |
| 7. 分析結果 | 分析結果画面の指標タイルと「要注意度」タブ、「推移」タブ |

「AI処理ログ」タブとExcelの「AI処理ログ」シートで、どのデータを送り、どう返ってきたかを後から確認できます。
